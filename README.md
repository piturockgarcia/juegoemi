# JuegoEMI 🎮

Juego 2D para celular en pantalla horizontal, inspirado en la época de los juegos de MS-DOS y con personajes y sprites propios.

## Objetivo inicial
- Movimiento lateral
- Salto
- Enemigos
- Objetos coleccionables
- Puntuación
- Niveles
- Soporte para controles táctiles

## Estructura
Los gráficos y sonidos estarán dentro de `assets/` y la lógica principal del juego se desarrollará en JavaScript.
